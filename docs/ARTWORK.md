# 图标来源与制作

插件图标为按用户提供的人物参考重新生成的双人 Q 版插画；用户已确认采用第三版。

- GPT 娘参考：用户提供的白发紫眼龙娘图片，以及 https://github.com/weit0529/gpt-pet 。保留龙角、白发和结形发饰。
- DeepSeek 娘参考：用户提供的蓝发鲸鱼女仆图片。保留鲸鳍耳、鲸尾、女仆头饰和鲸鱼围裙图案。
- 构图：两个人物共同手持相连聊天气泡，透明背景。

本项目 MIT 许可证适用于本项目代码；不声称拥有第三方原始角色参考图的权利，也不把原始参考图打入发行包。图标不代表 OpenAI 或 DeepSeek 的官方背书。

运行图标从用户批准的 v3 等比导出：256px PNG 为114306字节，128px PNG为32270字节，保留alpha；原图单独保留。DSH宿主实际支持PNG/SVG等，图标上限256KiB，verify会校验导出路径和文件大小。小尺寸会简化可见细节，不声称16px下仍能辨识全部配饰。
